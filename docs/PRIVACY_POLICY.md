GradeLens ("the app") is operated by [your name / institution] ([contact email]). It is used only by teachers to evaluate student assignments.

## Information we process
- **Teacher account:** name, email address and profile photo from Google Sign-In; profile details the teacher enters (designation, department, institution, phone, subjects).
- **Google Drive access:** with the teacher's permission the app reads the Drive folders and Google Sheets the teacher links, and creates result spreadsheets the teacher exports. It does not modify or delete other files.
- **Class data:** student names and roll numbers imported by the teacher, assignment questions, marks, feedback and remarks.
- **Student submissions:** files are read from the teacher's Drive at evaluation time. Page images are cached temporarily on the server and deleted automatically.

## How information is used
Only to provide the evaluation service: matching submissions to students, generating answer keys, grading, detecting duplicate submissions and exporting results. Submission content is sent to the Claude API (Anthropic) for evaluation. Under Anthropic's commercial terms, API data is not used to train models by default.

## Sharing
We do not sell data or use it for advertising. Data is shared only with service providers needed to run the app: Google (sign-in, Drive, Sheets), Anthropic (AI evaluation) and our hosting/database providers.

## Retention and deletion
Data is kept while the teacher's account exists. Teachers can export their data (Settings → Export my data) and permanently delete their account and all associated classes, students and results (Settings → Delete account). Google access can also be revoked at https://myaccount.google.com/permissions.

## Security
Connections use HTTPS. Google access tokens are encrypted at rest. Each teacher can access only their own data.
